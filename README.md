# АЛРОСА ИТ — Система аудита миграции на отечественное ПО

Комплексная система оценки готовности рабочих мест к переходу на отечественные операционные системы и программное обеспечение.

## Возможности

### 🎯 Основной функционал
- **Загрузка реестра АРМ** — импорт данных о рабочих местах из CSV/Excel
- **Анализ совместимости** — автоматическая проверка железа и софта
- **Определение блокеров** — выявление критического ПО без аналогов
- **Группировка по волнам** — распределение АРМ по этапам миграции
- **Визуальная панель** — современный интерфейс с графиками и метриками

### 📊 База знаний
- **Матрица совместимости** — 60+ наименований ПО с аналогами
- **Профили ОС** — 4 отечественных дистрибутива (Astra, РЕД ОС, Альт, Rosa)
- **Категории ПО** — офисные пакеты, браузеры, САПР, графика, безопасность и др.
- **Справочник аналогов** — отечественные замены импортного софта

## Быстрый старт

```bash
cd alrosa-it-final
docker compose up --build
```

Откройте браузер: **http://localhost:3000**

API документация: **http://localhost:8000/docs**

## Тестовый датасет

В папке `data/` находится файл `sample_workstations.csv` с 25 тестовыми АРМ.

## Технологии

- Backend: FastAPI + PostgreSQL + SQLAlchemy + Pandas
- Frontend: React + Vite
- База данных: PostgreSQL 16
- Контейнеризация: Docker Compose

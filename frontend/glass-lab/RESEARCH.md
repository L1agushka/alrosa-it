# ALROSA Optical Lab — изолированный прототип

Адрес при работающем Vite: http://127.0.0.1:5173/glass-lab/

Это отдельная HTML-точка входа, а не маршрут App. Она не импортирует рабочие компоненты, CSS приложения, API или engine.js. Лендинг, навигация продукта, данные и бизнес-логика не изменены в этой итерации. Существующие незакоммиченные изменения сохранены. Новых npm-зависимостей нет.

## Материал и визуальный язык

- Сохраняются ALROSA IT, грань алмаза, Manrope и ледяной голубой. Стенд называется Arctic Optics; это исследование материала, не предложение заменить лендинг.
- Чернильный фон `#0b121a`, основной текст `#edf3f8`, вторичный `#a5b3c0`, холодный акцент `#90c2d3`; светлое окружение `#edf1f0`. Семантические статусы продукта здесь не переопределяются.
- Крупная вводная типографика, компактные подписи и контрастный внутренний слой. Ритм 4/8/16/24/40/64. Скругления привязаны к демонстрации кривизны стекла, а не к новой системе всех компонентов приложения.
- Пять образцов: плавающая навигация, кнопки, панель, раскрывающееся меню, native dialog.
- Карта RG кодирует нормали и величину смещения по закруглённому контуру. `feDisplacementMap` реально искажает изображение за элементом. Внутри плоской области смещение близко к нулю.
- Отдельная карта блика имитирует направленное освещение кромки; маска tint удерживает читаемость центра. Это экранная оптическая аппроксимация, не трассировка лучей и не физическая симуляция стекла во всём объёме.
- RGB включается отдельно: три слегка отличающихся смещения и цветовые матрицы создают хроматическую дисперсию. По умолчанию один проход, чтобы снизить стоимость отрисовки.
- Нет постоянно движущегося фона. Hover кнопки — 180 мс, появление меню/диалога — 160/200 мс. Reduced motion выключает переходы и анимации.
- Контрольная сетка показывает одинаковую поверхность со смещением 0 слева и регулируемым смещением справа. Регулятор, RGB и fallback позволяют проверить эффект непосредственно.

## Поддержка и производительность

SVG URL backdrop-фильтр включён только для Chromium по консервативной проверке user agent. Одного CSS.supports недостаточно для проверки реального рендеринга. Проверено на установленном Chromium 1234 из Playwright; универсальная поддержка всех Chromium-производных не утверждается.

Для других движков — матовая поверхность с blur и плотным tint. При отсутствии backdrop-filter, reduced transparency или forced colors предусмотрена непрозрачная поверхность. Переключатель Fallback позволяет явно проверить упрощённый вид. Нативные Safari/Firefox в этой среде не запускались; автоматический fallback на них не равнозначен браузерному тестированию.

Карты пересчитываются только при изменении геометрии; кэш ограничен 32 вариантами. Нет npm-пакетов для анимации или WebGL. Полный SVG-эффект остаётся дорогим при больших площадях и множестве поверхностей, поэтому его нельзя без дальнейших измерений переносить на все строки реестра или все панели продукта.

В headless Chromium при программной прокрутке 90 кадров, viewport 1440×1000:
- RGB: медиана около 50 мс, p95 около 83 мс.
- Один проход: медиана около 33 мс, p95 около 33 мс.

Это сравнительное измерение в конкретной среде, не гарантия 30/60 fps на устройстве пользователя. Проверка реального GPU, слабых рабочих станций и Safari/Firefox остаётся условием возможного внедрения.

## Выполненные проверки

Артефакты в `output/playwright/glass-lab/`:
- `before-landing.png`, `before-app.png`: исходный интерфейс текущей рабочей копии перед интеграцией каких-либо новых стилей.
- `dark.png`, `light.png`, `contrast.png`: три окружения.
- `proof.png`, `refraction-off.png`, `refraction-on.png`: визуальная проверка изгиба сетки при одинаковом фоне. Смещение видно у кромки, а не только как размытие.
- `dropdown.png`, `modal.png`, `fallback.png`, `mobile.png`.
- `zoom-equivalent.png`: viewport 720×500, эквивалентный доступной CSS-площади при 200% на 1440×1000. Это проверка reflow, не тест реального browser zoom.
- `checks.json`: размеры, фокус, сеть и измерение кадров.

Проверены 1440, 720, 390 и 320 CSS px; горизонтального переполнения документа нет. Меню закрывается Escape и кликом снаружи; после выбора фокус возвращается к кнопке. Native dialog удерживает Tab, закрывается Escape, возвращает фокус к открывшей его кнопке. У диалога есть доступное название, у полей — подписи, у элементов — видимый фокус. Reduced motion даёт transition-duration 0s. JavaScript page errors: 0. Запросов стенда к `/api/`: 0.

После просмотра светлого/контрастного фона добавлена стабильная тёмная подложка внешних подписей и уплотнён центр диалога. Полная сертификация WCAG и автоматическая проверка всех пиксельных контрастов не проводились.

Отдельная сборка успешна:

```sh
cd frontend
node node_modules/vite/bin/vite.js build glass-lab --outDir /tmp/alrosa-glass-build
node_modules/.bin/oxlint glass-lab
```

В этой среде Vite запускался имеющимся Node из bundled runtime, потому что системный Node 18 старше требований проекта. Никакой runtime в зависимости проекта не добавлен. Playwright запущен через уже установленный API и браузер, без установки CLI или библиотек.

Обычная production-сборка приложения не включает этот стенд: конфигурация приложения специально не менялась. Для дальнейшего использования сначала требуется решение пользователя о материале и конкретных поверхностях.

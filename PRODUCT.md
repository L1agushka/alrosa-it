# ALROSA IT

Учебный инструмент для ИТ-команды: инвентаризация рабочих мест, правила подразделений, блокеры и волны перехода на отечественное ПО. Основное действие — загрузить CSV/XLSX; следующий шаг — проверить причины и выбрать пилот. Пользовательские роли admin, analyst, viewer уже реализованы; права и API сохраняются при визуальных изменениях. ML — отдельный исследовательский прогноз на синтетической выборке. Совместимость подтверждается пилотом.
